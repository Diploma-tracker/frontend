# Environment variables

| Variable             | Meaning                                           | Requirement | Default value                               |
| -------------------- | ------------------------------------------------- | ----------- | ------------------------------------------- |
| `OPENAPI_SCHEMA_URL` | Backend OpenAPI schema URL for client generation. | Optional    | `http://localhost:8000/schema/openapi.json` |

## Documentation rule

Document every environment variable in this file and [`.env.example`](../.env.example).
Update both files when adding, changing, or removing a variable.
