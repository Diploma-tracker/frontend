# `@repo/ui-kit`

This package contains the UI components for the repository. It is built using React and TypeScript, and it is designed to be used in conjunction with the other packages in the repository.

## Scripts

Watch TypeScript components for changes.

```bash
dev:components
```

Watch Tailwind CSS builds for styles.

```bash
dev:styles
```

Build TypeScript components.

```bash
build:components
```

Build Tailwind CSS styles.

```bash
build:styles
```

Lint source files with ESLint (no warnings allowed).

```bash
lint
```

Fix ESLint issues in source files.

```bash
lint:fix
```

Check formatting with Prettier.

```bash
format
```

Fix formatting with Prettier.

```bash
format:fix
```

Type-check without emitting files.

```bash
check-types
```

Clean the build output directory called `dist`.

```bash
clean
```
